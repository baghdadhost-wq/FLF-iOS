# FLF-iOS
## LF2 الأصلية (lf2/)

نسخة ثانية تشغّل Little Fighter 2 v1.9 الأصلية داخل محاكي Windows 95 ([v86](https://github.com/copy/v86))، مبنية على [Cludes/r-lf2-web](https://github.com/Cludes/r-lf2-web).
- تُبنى إلى `LF2.ipa` (إصدارات `lf2-build-N`).
- أول تشغيل يحمّل قرص اللعبة (~95 ميغا) من المستودع الأصلي مرة واحدة ثم تعمل بدون إنترنت.
- زر «كشف ★» يكتب `lf2.net` في شاشة الاختيار فتظهر كل الشخصيات المخفية.
